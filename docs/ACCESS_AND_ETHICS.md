# Planet access, attribution, and ethics

1. Your ASU preliminary registration was submitted November 3, 2026. Planet invitation was not yet confirmed at project creation.
2. Verify exactly which Planet product, API scope, monthly cap, downloading, public publication, and other limits apply to the ASU organizational agreement before collecting data.
3. Planet's publicly described Education & Research Basic program permits **limited noncommercial** research and expressly says Planet data must not be sold or used to develop tools/products that might be sold. An ASU contract could differ; follow the agreement that applies to your account and ask newspace@asu.edu when uncertain.
4. Keep raw imagery, exports, API keys, and account authentication out of git and any public release. Never paste API keys into a chat or public issue.
5. Attribution guideline from Planet Education & Research: 'Planet Team (20xx). Planet Application Program Interface: In Space for Life on Earth. San Francisco, CA. https://api.planet.com.' Check the applicable agreement and replace 20xx with correct year when used.
6. Code can be public, but never publicly release copyrighted imagery without explicit authorization; publication of figures is subject to license terms.
7. The project belongs to a research portfolio, not a commercial Reel One service. If later pursuing commercialization, obtain separate licensed datasets/permissions and a new evaluation plan before using them for a product.
8. External AI tools should only receive scene-derived data if the applicable Planet agreement permits such sharing; default is not to upload licensed raw imagery to external AI services.
